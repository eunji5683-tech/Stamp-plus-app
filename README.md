# 풀문지카페 단골 적립 스탬프

계산할 때 손님의 **휴대폰 번호 뒤 4자리**로 스탬프를 찍어 주고, **10개를 모으면 무료 음료**를 드리는 웹앱이에요.
HTML, CSS, JavaScript만 사용했고 별도 설치 없이 브라우저에서 바로 열려요.

## 한눈에 보기
- 스탬프 기록은 **사장님 휴대폰 안에만** 저장돼요. 인터넷 서버로 보내지 않아요.
- 저장하는 정보는 **번호 뒤 4자리와 스탬프 개수뿐**이에요. 이름과 앞자리는 받지 않아요.
- 손님은 자기 휴대폰으로 개수를 볼 수 없고, 직원이 알려 줘요. 손님 화면(QR)은 **이용 안내만** 보여줘요.

## 화면 구성
| 파일 | 누가 쓰나요 | 하는 일 |
|---|---|---|
| `index.html` | 손님 | QR로 열면 **이용 방법 안내**만 보여줘요. 사장님 휴대폰에서 "손님 확인 화면 열기"로 들어오면 번호를 넣고 **스탬프 동그라미 10개**와 축하 화면을 보여줘요. |
| `admin.html` | 직원 (비밀번호 필요) | 적립, 취소(1개 빼기), 사용 완료(0개로 되돌리기), 오늘 적립 횟수, 백업과 복구 |
| `운영안내.txt` | 직원 | 개발을 몰라도 따라 할 수 있는 매장 운영 안내서 |
| `apps-script.gs` | (쓰지 않아요) | 나중에 구글 시트에 저장하는 방식으로 바꾸고 싶을 때를 위해 남겨 둔 코드 |
| `CLAUDE.md` | 개발 도우미 | 이 프로젝트를 만들 때 지킨 작업 규칙 |

## 관리자 화면 기능 (`admin.html`)
- 비밀번호 4자리를 입력해야 들어가요. 5번 틀리면 30초 동안 막혀요.
- **적립**: 번호를 넣고 누르면 스탬프 +1. 현재 개수가 바로 보여요.
- **취소**: 실수했을 때 스탬프 -1.
- **10개가 되면** "무료 음료 제공 대상입니다" 알림이 뜨고 적립이 잠겨요.
- **사용 완료**: 음료를 드린 뒤 누르면 0개로 되돌려요. 확인 창이 두 번 떠요.
- **실수 막기**: 번호가 4자리가 아니면 버튼이 눌리지 않아요. 같은 손님에게 1분 안에 또 적립하면 "방금 적립했습니다. 계속할까요?"라고 물어요.
- **오늘 적립한 총 횟수**가 화면 아래에 보여요. 날짜가 바뀌면 0부터 다시 세요.
- **백업**: "백업 내려받기"로 기록을 파일로 보관하고, "백업 불러오기"로 되살려요. 마지막 백업 후 7일이 지나면 화면 위에 안내가 떠요.

## 시작하기
1. `admin.html` 맨 위 "★ 고치는 곳"에서 **관리자 비밀번호(`ADMIN_PIN`)를 내 번호로 바꿔요.** 처음 들어 있는 `7531`은 누구나 아는 임시 번호예요.
2. `index.html` 맨 위에서 `SHOW_DEMO_NOTE`를 `false`로 바꿔요. 연습용 가짜 번호가 꺼져요.
3. 가게 이름, 스탬프 개수, 보상 이름도 각 파일 맨 위에서 바꿀 수 있어요. 두 파일(`index.html`, `admin.html`)을 똑같이 맞춰 주세요.
4. 아이폰에서는 사파리로 관리자 주소를 열고 **공유 버튼 → 홈 화면에 추가**를 해서, **그 아이콘으로만** 열어요. 사파리와 홈 화면 아이콘은 저장 칸이 따로라서 섞어 쓰면 기록이 안 보일 수 있어요.

자세한 매장 사용법은 `운영안내.txt`를 보세요.

## ⚠️ 꼭 알아둘 점
- **관리자 비밀번호는 `admin.html` 안에 적혀 있어요.** 이 저장소를 공개(Public)로 두면 누구나 볼 수 있으니, 꼭 내 번호로 바꿔서 쓰세요. 손님 기록은 파일에 들어 있지 않아서, 저장소가 공개여도 손님 정보는 새지 않아요.
- 기록이 **휴대폰 한 대 안에만** 있어요. 휴대폰을 바꾸거나 인터넷 기록을 지우면 사라질 수 있으니 **일주일에 한 번 백업**하세요. 백업 파일에는 손님 번호 뒤 4자리가 들어 있으니 인터넷에 올리지 마세요.
- 같은 뒤 4자리를 가진 손님이 두 명이면 스탬프가 섞여요. 손님이 많아지면 구분 방법이 필요해요.
- `admin.html`의 주소는 손님에게 알리지 마세요.

## 구글 시트로 바꾸고 싶다면 (선택)
지금은 쓰지 않지만, 손님이 자기 휴대폰에서도 스탬프를 보게 하고 싶다면 `apps-script.gs`를 구글 시트에 붙여 넣고 두 화면의 `SHEET_URL`에 주소를 넣으면 돼요. 이때는 번호 뒤 4자리와 개수가 구글 계정에 저장되니, 손님에게 알리는 안내가 필요해요.

## 사용한 것
HTML, CSS, JavaScript만 사용했어요. 리액트 같은 복잡한 도구는 쓰지 않았어요.
디자인은 연두색과 크림색의 글래스모피즘 스타일이고, 글꼴은 고운 돋움(없으면 맑은 고딕)이에요.
